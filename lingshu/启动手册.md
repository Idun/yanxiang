# 灵枢（NOVA）启动手册

个人 AI 长篇小说工作室。

## 环境要求

- Windows 10/11（macOS / Linux 命令类似）
- Python **3.12+**
- Node.js **18+**
- 自备 [DeepSeek](https://platform.deepseek.com/) API Key（没有 Key 也能建书、手改章节，但无法调用 AI）

## 一、启动后端

在终端中执行：

```powershell
cd 本目录\apps\api
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

看到 `Application startup complete` 即表示后端就绪。

- API 文档：http://127.0.0.1:8000/docs  
- 首次启动会自动在 `data/` 下创建空的 `nova.db`

若 `py -3.12` 不可用，可改用 `python -m venv .venv`。

## 二、启动前端

**另开一个终端**：

```powershell
cd 本目录\apps\web
npm install
npm run dev
```

浏览器打开：http://localhost:5173

## 三、填写 API Key

任选一种方式：

### 方式 A：网页设置（推荐）

1. 打开 http://localhost:5173  
2. 点顶部「设置」  
3. 填入 DeepSeek API Key 并保存  

### 方式 B：编辑环境文件

编辑 `apps/api/.env`：

```
DEEPSEEK_API_KEY=sk-你的密钥
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

保存后若后端已在跑，一般会自动重载；不行就重启一次 `uvicorn`。

也可编辑 `data/settings.json` 里的 `deepseek_api_key`（网页设置写入的也是这个文件）。

## 四、开始使用（最短路径）

1. 首页点「创建作品」  
2. 在设定页用各字段旁的 AI 聊简介 / 世界观 / 角色 / 大纲，**确认后才会写入**  
3. 点「去写章」→ 可先「规划本卷剧集」→ 改剧情要点 →「生成并过审」  
4. 用「预览」看阅读效果；满意后可「锁定」章节


## 六、常见问题

**前端能开，AI 报错 / 提示未配置 Key**  
→ 检查设置页或 `apps/api/.env` / `data/settings.json` 是否已填 Key。

**端口被占用**  
→ 改后端端口：`uvicorn app.main:app --reload --port 8001`，并确认前端代理/CORS 是否指向新端口（默认 CORS 含 `5173`）。

**数据库在哪**  
→ `data/nova.db`。删除该文件等于清空所有作品（请先备份）。

## 七、日常再次启动

依赖装过之后，每次只需：

```powershell
# 终端 1
cd 本目录\apps\api
.\.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

# 终端 2
cd 本目录\apps\web
npm run dev
```

祝写作顺利。
