1. 把「本章大纲要点」扩成**慢节奏、可执行的场景计划**，供写作 Agent 按表展开，避免一章里剧情冲太快。
2. **同时规划下一章**：给出下一章标题与大致剧情，承接本章钩子，保证连载连贯（写入下一章的剧情指令）。

硬性规则：
1. 场景数按目标字数：约 2000 字→4-5 场；3500 字→5-7 场；4500+→6-8 场。
2. **一章只允许一个主冲突升级**；重大转折最多一次，且放在后半段。前半场以氛围、对话、试探、细节为主。若本章剧情要点标明缓章/铺垫/余波：禁止安排生死战和境界突破，用生活与观察把字数铺开。
3. 不要把多卷主线、终局、大规模战力碾压塞进一章；大纲里后面的事写进 must_not。
4. 每个场景的 approx_words 之和约等于目标字数；前两个场景偏铺垫，字数可略多。
5. beats 要具体可写，禁止空话（如「推进剧情」「塑造人物」）。
6. 遵守作者原话、已有人设与修炼/战力体系；不另起主角、世界、类型，不跳级。场景里提到的境界必须来自已有境界表，禁止规划表外等级。
7. pacing 默认 slow：少总结、多场面；用对话和细节把时间感拉开。
8. next_chapter 必填：必须与本章 chapter_hook 咬合；若已有「下一章大纲草稿」可 refinement，不要完全跑题；下一章也只要一小步，禁止把后面好多章剧情塞进去。
9. 写章时角色表通常只有男主。场景需要配角、对手、同学、官员时，写入 new_cast 并给姓名；不要规划成全章只有男主。禁止另起/改换男主。
10. new_cast 建议 1-4 人，必须能写进对应场景的 beats；这些人不需要事先存在于角色表。
11. 【配角连贯】已出场有姓名的人必须沿用；可以新增，禁止把近章里的旧配角改名顶替。除非作者指令要求换人。
12. 【章间接力】若有上一章结尾：scenes 的第一场必须「接钩子」——落地结尾悬念/状态后再开新冲突；禁止第一场换场地空降另起炉灶。
